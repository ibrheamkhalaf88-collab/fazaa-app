# خطة تطوير الذكاء الاصطناعي في فزعة

**الهدف:** مساعد بيجاوب المرأة بعامية واضحة ومن نص القانون بس، بيعرف يسأل لما السؤال ناقص، وبيعترف لما ما بيعرف،
ومحامية بتراجع شغله بشكل مستمر.

**قاعدة ما بتتغير:** النموذج ما بيجاوب إلا من مواد قانونية انسحبت للسؤال، وكل استشهاد بينفحص. أي تطوير ما بيكسر هالقاعدة.

الأسبوع تقريبي وبيعتمد على وقت المحاميات (أهم اعتماد بالخطة). ✅ تم · ⏳ جاري · ⬜ لسا.

---

## المرحلة أ: إصلاح الأساس (أسبوع 1) ⬜

**ليش:** تعليمات النموذج لسا مكتوبة للابتزاز بس، والقوانين الجديدة (نفقة، طلاق، حضانة) ما إلها تعليمات.

| #   | المهمة                                                                                                                                                  | مين                       |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| 1   | كتلة تعليمات لكل موضوع: ابتزاز/صور، نفقة، طلاق، حضانة، القانون الأساسي. كل كتلة لها خطواتها الخاصة (مثلاً الطلاق: الوثائق، المحكمة الشرعية، طلب محامية) | Claude                    |
| 2   | حد استرجاع متغيّر: 3 مواد للسؤال البسيط و5 للطلاق والنفقة                                                                                               | Claude                    |
| 3   | اختبار آلي: جواب الطلاق ما بيحتوي "بلّغي عن الحساب" ولا خطوات الابتزاز                                                                                  | Claude                    |
| 4   | ضم `npm run ai:eval` للفحص التلقائي على GitHub                                                                                                          | Claude                    |
| 5   | إضافة 40 سؤال عائلة (ضفة وغزة) لـ `ai-data/eval/questions.json`                                                                                         | Claude، ثم المحامية تصحّح |

**معيار النجاح:** كل أسئلة التقييم بتطلع زي المتوقع، والاختبارات خضرا.

## المرحلة ب: أول اختبار حقيقي (أسبوعين 2–3) ⬜

| #   | المهمة                                                                     | مين       |
| --- | -------------------------------------------------------------------------- | --------- |
| 1   | مفتاح Gemini **جديد** (القديم انكشف). بتدخليه من لوحة المطور بس            | إبراهيم   |
| 2   | رفع آخر نسخة وتجربة "اختبار الاتصال" من اللوحة                             | إبراهيم   |

**معيار النجاح (أهداف مقترحة، بتتعدل مع المحامية):**

- 90% أو أكتر من الأجوبة "جيد".
- صفر استشهاد غلط (مفروض آلياً أصلاً).
- 100% من الأسئلة برا النطاق بترجع "غير مغطى".
- أي جواب فيه معلومة قانونية غلط = إيقاف الإطلاق لحد الإصلاح.

## المرحلة و: لاحقاً ⬜

- **نماذج مخصصة (fine-tuning):** بس بعد ما يتجمع حوالي 1000 جواب مراجَع، وبعد قرار قانوني بخصوص استخدامها.
- **قوانين ناقصة:** حضانة غزة، تعديل سن الزواج 2019، قانون العقوبات، المواريث.
- **لغات وصيغ:** صوت (المايك موجود جزئياً)، ولاحقاً الإنجليزية.

## شو لازم يتوفر

1. **وقت المحاميات** (شرط أساسي للمراحل ب و د و هـ).
2. مفتاح Gemini جديد وحدّ استخدام مناسب.
3. رفع الموقع بآخر نسخة قبل كل مرحلة (التطبيق ما بينشر تلقائياً).

## المخاطر والرد عليها

| الخطر                                 | الرد                                                                        |
| ------------------------------------- | --------------------------------------------------------------------------- |
| جواب قانوني غلط                       | استرجاع محصور + فحص الاستشهاد + مراجعة المحامية + إيقاف الإطلاق إذا ظهر خطأ |
| نص مادة غزة غير دقيق (نسخة غير رسمية) | محامية بتتحقق منه قبل الإطلاق، و`npm run law:verify` للضفة                  |
| خصوصية السياق                         | ما بنخزّن، بس بنعلن بالموافقة. وبنقدر نعطّله                                |
| تكلفة أو حدّ الاستخدام                | حد يومي (`AI_DAILY_LIMIT`)، ونموذج خفيف افتراضياً                           |
| العامية بتختلف                        | مرادفات من أسئلة المحاميات، وتحديث شهري                                     |

## كيف نعرف إنه تحسّن

مقاييس بتنقاس قبل وبعد كل مرحلة، بنفس الأسئلة:

- نسبة الأجوبة "جيد" من مراجعة المحامية.
- نسبة "غير مغطى" الصحيحة برا النطاق، ونسبة "غير مغطى" الغلط داخل النطاق.
- recall@5 للاسترجاع.
- عدد الأسئلة التوضيحية المفيدة (حسب مراجعة المحامية).
