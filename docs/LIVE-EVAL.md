# تقييم Gemini الحقيقي (`scripts/live-eval.mjs`)

بيشغّل كل سيناريوهات التقييم المصطنعة (`tests/fixtures/assistant-scenarios.js`) على **المسار الحقيقي للتطبيق**:
التطبيق (`answerer`) ← فحص الرد بالعميل ← خطوة السيرفر (`answerQuestion`: الخطر أول، النصوص، البرومبت،
إعادة المحاولة، الـcircuit breaker) ← Gemini. كل محادثة بتنشغل مرتين: «رسالتي بس» و«مع آخر الرسائل».
ما في ولا جملة من مستخدمة حقيقية.

## 1. تجربة بدون تكلفة (مزوّد وهمي، بدون إنترنت)

```bash
npm run ai:live-eval -- --dry-run
```

## 2. التشغيل الحقيقي

المفتاح بس بمتغيّر بيئة بالتيرمينال تبعك. السكربت ما بيطبعه وما بيكتبه بأي ملف.

```powershell
$env:GEMINI_API_KEY = "…"   # لهالنافذة بس
```

```bash
npm run ai:live-eval -- --live --cap-usd 5 --model gemini-3.5-flash-lite
```

- أول إشي بيجيب قائمة النماذج المتاحة للمفتاح (مجانية، بدون توكنز)، وبيوقف إذا النموذج مش موجود.
  وبينبّه إذا النموذج الاحتياطي (`gemini-3.5-flash` بالكود) مش موجود. صفحة الأسعار بتاريخ 2026-11-13 ما فيها،
  فغالباً لازم `--fallback-model gemini-3.6-flash` أو تعديل `FALLBACK_MODEL`.
- **السقف:** لما التكلفة المحسوبة (من عدّ التوكنز اللي بيرجّعه Google) توصل `--cap-usd`، السكربت بيوقف الطلبات
  وبيكمّل بالردود المحلية.
- الحصة المجانية: البيانات مصطنعة فما في مشكلة خصوصية، بس حدودها بطيئة، فاستعملي `--delay-ms 4000`
  وأرقام الزمن رح تكون مش دقيقة.
- لتجربة صغيرة أول: `--only C01,C05,L22 --modes context`.

## 3. الناتج

`docs/evidence/live-eval-<model>-<date>.txt` (كل المحادثات) و`.json` (الملخص):

| الحقل | شو بيعني |
|---|---|
| `aiRate` | من الرسائل اللي راحت للنموذج، قديش رجع رد عدّى كل الفحوصات |
| `providerErrors` | أخطاء المزوّد حسب النوع (مشغول، مهلة، circuit مفتوح، سقف) |
| `validationRejections` | ردود رفضها التطبيق: قانون بدون مصدر، رقم مش بالنص، وعد ممنوع |
| `structuralFailures` | رد خالف شرط ثابت: خطر بدون أمان، اقتباس ممنوع، نصايح لما بدها تنسمع |
| `otherDialect` | ردود فيها كلمات من لهجة تانية |
| `tooLong` | ردود أطول من 5 جمل |
| `questionRepeated` | نفس السؤال انسأل مرتين بنفس المحادثة |
| `latencyMs` | زمن الرد p50 وp95 |
| `cost` | عدد الطلبات، التوكنز، والتكلفة المحسوبة بالدولار |

الأرقام الآلية **مش كافية**: بعدها محامية بتراجع عيّنة ردود القانون، ومختصة حماية بتراجع الردود الحساسة
(صحة، أمان، احترام، فائدة عملية).
