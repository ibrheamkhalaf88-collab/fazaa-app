## 5. التشغيل والتطبيق والنشر والرجوع

```bash
git switch audit/closed-beta
node --test tests/
npx eslint src server tests scripts
node scripts/dev-server.mjs                       # مع خدمة المحامية محلياً
```
للتجربة المحلية بإعداد النسخة العامة ومزوّد وهمي: إعداد `app-public-config` بـ `.claude/launch.json`.

النشر (ما نفّذته، بدو تفويضك): ادمج الفرع، ثم
```bash
node scripts/build-admin.mjs
cd server/api && npx wrangler deploy
```
`server/api/public/` **ملف مولّد** من `scripts/build-admin.mjs`: لا تعدّله يدوياً.
الرجوع: `npx wrangler rollback` (للإصدار السابق على Cloudflare) أو `git switch master` وإعادة البناء والنشر.
ما في ترحيل قاعدة بيانات بهالتدقيق، فالرجوع ما بيلمس البيانات. غيّرت `CACHE_VERSION` لـ `fazaa-v23` عشان الأجهزة تاخد النسخة الجديدة.
