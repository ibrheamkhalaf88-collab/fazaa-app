# استقبال ملفات القوانين: الضفة الشرعي، الضفة النظامي، غزة النظامي

آخر تحديث: 2026-11-21. هذا الدليل لإدخال أي قانون جديد إلى فزعة **بدون ما يختلط** مع قانون منطقة ثانية أو محكمة ثانية.

## الصناديق الخمسة

كل قانون بيسكن في صندوق واحد بس. الصندوق هو اللي بيحدد المنطقة والمحكمة، مش القانون نفسه:

| الصندوق        | المجلد                       | المنطقة  | المحكمة    | الحالة الآن                                                                                                    |
| -------------- | ---------------------------- | -------- | ---------- | -------------------------------------------------------------------------------------------------------------- |
| `gaza-sharia`  | `src/data/law/gaza/sharia/`  | قطاع غزة | الشرعية    | فعّال: حقوق العائلة 1954، أبو حنيفة، أصول 1965، التنفيذ الشرعي 6/2021                                           |
| `gaza-nizami`  | `src/data/law/gaza/nizami/`  | قطاع غزة | النظامية   | فعّال: الجرائم الإلكترونية، العقوبات 1936 بتعديلاته لحد 1984، الإجراءات الجزائية 3/2001. الباقي بانتظار المحامي |
| `gaza-general` | `src/data/law/gaza/general/` | قطاع غزة | قواعد عامة | فعّال: مجلة الأحكام، الكتاب 14                                                                                  |
| `wb-sharia`    | `src/data/law/wb/sharia/`    | الضفة    | الشرعية    | **جاهز وفاضي** (`awaiting-texts`)                                                                              |
| `wb-nizami`    | `src/data/law/wb/nizami/`    | الضفة    | النظامية   | **جاهز وفاضي** (`awaiting-texts`)                                                                              |

قانون موجود بالمنطقتين (مثلاً أصول المحاكمات المدنية 2/2001) **ما بينشارك**: بياخد نسخة لكل صندوق، بتعديلات منطقته،
وبرمز خاص، ومراجعة محامي منفصلة.

## خطوات إدخال قانون

1. **النص من المحامي فقط**، أو من مصدر رسمي وافق عليه المحامي. حوّله لملف JS بنفس شكل الملفات الموجودة
   (`docs/sources/gaza/pipeline/` لطريقة التفريغ والتدقيق). الملف بيصدّر `XXX_NAME` ومصفوفة مواد
   `{id, number, topic, url, amended, text}`. احفظ **آخر نص نافذ** بالمنطقة، واكتب بـ `amended` القانون المعدِّل.
2. **حطّه بمجلد الصندوق الصحيح**، مثلاً `src/data/law/wb/sharia/personal-status-1976.js`.
3. **سجّله بـ `index.js` تبع نفس المجلد** (مش بالسجل العام):
   ```js
   {
     key: "wb-personal-status-1976",       // فريد بكل الصناديق
     name: "قانون الأحوال الشخصية رقم 61 لسنة 1976",
     prefix: "wps:",                        // الضفة: لازم يبلش بـ w. غزة: ممنوع يبلش بـ w
     articles: PERSONAL_STATUS_1976,
     hints: ["الاحوال الشخصيه 1976"],        // كلمات (بعد التطبيع) بتسمّي القانون بسؤال «المادة 66 من …»
     marks: ["1976"],                       // كلمات/سنين بتسمّي هالقانون وما بتسمّي أي قانون بالمنطقة الثانية
     caveat: "",                            // سطر تحذير تحت كل جواب بيستشهد فيه (اختياري)
     conflicts: [],                          // {with, note}: لما قانونين بنفس المحكمة ممكن يختلفوا
     source: "…", scope: ["…"],
     review: { status: "pending", by: "", at: "" },
   }
   ```
   - كل مادة لازم يبلش رقمها بالـ `prefix` (`wps:66`).
   - **ممنوع** ملف بصندوق يستورد من صندوق ثاني (الاختبار بيمسكها).
   - `marks` هي اللي بتخلي جواب لمستخدمة غزة ينرفض إذا ذكر قانون الضفة، والعكس، بدون أي تعديل بالكود.
4. **أضف الملفات لـ `sw.js`** (قائمة `PRECACHE`) وارفع `CACHE_VERSION`.
5. **شغّل `npm test`**. `tests/law-separation.test.js` بيتأكد من الفصل، و`tests/law-integrity.test.js` لازمه بصمة
   للمواد الجديدة (شوف رأس الملف).
6. **كلمات البحث** (اختياري بس مهم للدقة): كلمات عامية للمواضيع بـ `TOPIC_KEYWORDS` / `TOPIC_RULES`، وأرقام المواد
   للمواضيع بـ `INTENT_TO_ARTICLES` في `src/data/law/index.js`. موضوع جديد لمحكمة معيّنة: أضفه لـ `INTENT_COURTS`.

## تفعيل صندوق الضفة

صندوق `awaiting-texts` **ما بيوصل للتطبيق** حتى لو فيه ملفات. لما يوافق المحامي:

1. غيّر `status` للصندوق في `src/data/law/corpora.js` إلى `"active"`.
2. تعديل اختبار «the West Bank boxes are ready and empty» بـ `tests/law-separation.test.js` (قرار مقصود).
3. **فتح الضفة للمستخدمات قرار منفصل**: التطبيق لغزة بس (قرار المالك 2026-11-19). لفتحها لازم كمان:
   `src/core/state.js` (المنطقة)، `COUNTRIES` في `server/ai-proxy/worker.js`، رد «وإذا بالضفة؟» في
   `src/ai/answerer.js`، ولهجة البرومبت (`DIALECT`).

## شو بيضمن عدم الخلط (وبيفحصه الاختبار)

- **بين المناطق:** كل مستخدمة بتشوف صناديق منطقتها بس (`articlesFor`). جواب بيذكر قانون المنطقة الثانية بينرفض
  (`otherRegionLaw`، من `marks` كل قانون + قائمة ثابتة: 1976/1960/1959/الأردني لغزة، و1954/1936/1965/غزة للضفة).
- **بين المحاكم:** سؤال عائلي (نفقة، حضانة، طلاق، ميراث) ما بيجيه نص نظامي، وسؤال ابتزاز ما بيجيه نص شرعي، حتى لو
  تشاركوا كلمات (`keepCourtsApart`). سؤال بيمس الاثنين (عنف، تهديد) بياخد من الاثنين **بالتناوب**، والنموذج
  بيشوف كل نص موسوم بمحكمته (`court="…"`)، والبرومبت بيمنعه يقول إن نص شرعي بتطبقه النظامية أو العكس.
- **تحت كل جواب:** إذا النصوص من محكمتين، كل قانون بينكتب مع محكمته ومنطقته (`lawScope`).

## موادّ لوحة التحكم («القوانين»)

المواد اللي بيضيفها المحامي من لوحة التحكم إلها منطقة بس، **ما إلها محكمة**، وفي سجلات قديمة منطقتها «الضفة وغزة».
لحد ما ينضاف عمود محكمة بقاعدة البيانات (تعديل على D1 بيحتاج موافقة المالك)، بتعامل كقواعد عامة بتمشي مع أي محكمة.
